# Apple x86_64 ABI

Intel Macs use ordinary Intel 64/AMD64 instructions with Apple's macOS ABI and Mach-O. Reuse x86-64 instruction selection and make Apple a calling-convention/object-format follower. Current macOS no longer supports 32-bit Intel applications.

Source: https://developer.apple.com/documentation/xcode/writing-64-bit-intel-code-for-apple-platforms
